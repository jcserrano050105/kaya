# Sample payment details (for testing only)

Use these to try the worker **Payment details** card and the customer **Payments** screen.
They are not a real GCash account: the number is a placeholder and the QR code only
contains the text "KAYA SAMPLE - not a real GCash account".

| Field | Type this |
|---|---|
| GCash account name | `Juan D. (Sample)` |
| GCash number | `0900 000 0001` |
| QR code | upload `sample-gcash-qr.png` from this folder |

Do not send real money to these details. Before real customers use the site, each worker
should replace them with their own GCash name, number and QR code.
