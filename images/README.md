# KAYA photos

The public pages (Home, Services, How It Works, Book a Service, Log In, Create Account,
Register as a Worker) show these photos when the files exist. A missing file is fine:
that spot shows the drawn illustration instead.

| File | Used for | Suggested size |
|---|---|---|
| `hero.jpg` | Home page hero (first slide) | 1920 × 1080 |
| `plumbing.jpg` | Plumbing card, carousels | 1600 × 1067 |
| `electrical.jpg` | Electrical card, carousels | 1600 × 1067 |
| `cleaning.jpg` | Cleaning card, carousels | 1600 × 1067 |
| `laundry.jpg` | Laundry card, carousels | 1600 × 1067 |
| `carpentry.jpg` | Carpentry card, carousels | 1600 × 1067 |
| `gardening.jpg` | Gardening card, carousels | 1600 × 1067 |

Use JPG, landscape, and keep each file under about 400 KB so pages load fast
(squoosh.app can shrink them). File names must be lowercase, exactly as above.
