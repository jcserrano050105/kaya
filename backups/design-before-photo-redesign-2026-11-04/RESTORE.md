# Saved design: before the photo redesign (2026-11-04)

This folder is a full copy of the website as it was before the realistic-photo
redesign: every page (`html/`), the stylesheet (`css/`), all scripts (`js/`),
the top-level `index.html` and `serve.json`.

## How to go back to this design
1. Stop the site if it's running.
2. Copy the `html`, `css` and `js` folders from this backup over the ones in the
   main `kaya` folder (replace the files).
3. Press Ctrl+F5 in the browser.

The database (Supabase) is not affected by restoring; only the look of the site changes.
